# DIV
Aplicacion para android simple, que accede a la antigua base de datos del ADA DNRPA para la busqueda de motor y chasis de vehiculos importados en Argentina. 

Para ello se tuvo que reestructurar la antigua base de datos que corria en ejecutables Windows. Dicha base de datos en formato .mdb se paso a .sql con un script en python, para luego hacer el APK correspondiente que consulte dicha DB. 

Se aclara que el archivo .mdb descargado de ADA DNRPA es de libre acceso y descarga. Como personal de la Policia de la Provincia de Cordoba, siendo Perito Verificador del Automotor, considero util la herramienta y, de hecho, la idea es hacerla escalable y colaborativa, para que se pueda generar un listado que perdure y sirva a futuros verificadores.
